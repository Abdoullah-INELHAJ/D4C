# D4C Premium Shopify Theme

A high-performance, conversion-optimized Shopify Online Store 2.0 theme inspired by Shrine Pro.

## Features
- **50+ Homepage Sections**: Before/After Slider, Comparison Tables, Shoppable Images, Vertical/Horizontal Tickers, Instagram-style stories, etc.
- **AJAX Cart Drawer**: Ultra-fast with free shipping goal and upsells.
- **Product Page Optimization**: Urgency labels, inventory counters, variant trust badges, and rich media blocks.
- **Premium Design**: Modern typography, smooth reveal-on-scroll animations, and custom video player.
- **Zero Third-Party Apps**: Built entirely with Vanilla Liquid, CSS, and JS.

## Tech Stack
- Shopify Online Store 2.0 (Json Templates)
- Vanilla JavaScript (ES6)
- Modern CSS (Custom properties)
- Swiper.js (for advanced carousels)

## Installation
1. Download the theme files.
2. Upload the ZIP to your Shopify store OR use Shopify CLI.
3. Configure your brand styles in the Theme Editor.
